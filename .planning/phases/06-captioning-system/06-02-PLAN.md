**1. Create `klippbok/services/caption_service.py`** with these functions:

`get_caption_style_for_project(manifest: dict) -> Literal["booru", "natural_language"]`:
- Check manifest for `caption_style_override` key first (CAPT-04)
- If override is "booru" or "natural_language", return it
- Fall back to active_profile's caption_style via `get_profile(manifest.get("active_profile", "sdxl"))`
- Default to "natural_language" if profile not found

`caption_image_for_project(image_path: Path, manifest: dict, vlm_config: CaptionConfig | None = None, general_threshold: float = 0.35) -> str`:
- Call `get_caption_style_for_project(manifest)` to determine style
- If "booru": lazy import `tag_image_booru` from `klippbok.caption.wd_tagger`, call it, join character tags + general tags with ", "
- If "natural_language": require vlm_config, create backend via `_create_backend(vlm_config)`, get prompt via `get_image_prompt()`, call `backend.caption_image(image_path, prompt)`
- Return the caption string

`save_caption(image_path: Path, caption: str, manifest: dict, image_id: str) -> None`:
- Write sidecar .txt file: `image_path.with_suffix(".txt").write_text(caption, encoding="utf-8")`
- Update manifest entry: find entry by image_id in `manifest["images"]`, set `entry["caption"] = caption`
- This function MUST be called for every caption write (generate, edit, batch) — see Pitfall 3 in research

**2. Add Pydantic models to `klippbok/api/models.py`:**

```python
class CaptionGenerateRequest(BaseModel):
    image_ids: list[str] | None = None  # None = all images
    style: Literal["booru", "natural_language", "auto"] = "auto"
    overwrite: bool = False
    provider: str | None = None  # for NL: "gemini", "replicate", "openai"
    api_key: str | None = None  # for NL backends
    general_threshold: float = 0.35

class CaptionStarted(BaseModel):
    operation_id: str

class CaptionProgress(BaseModel):
    operation_id: str
    current: int
    total: int
    message: str
    status: str  # "running" | "complete" | "error"

class CaptionUpdateRequest(BaseModel):
    caption: str

class CaptionUpdateResponse(BaseModel):
    image_id: str
    caption: str
    sidecar_written: bool
```

**3. Create `klippbok/api/routers/captions.py`** with:

`router = APIRouter(prefix="/captions", tags=["captions"])`

`POST /generate` — start batch caption generation:
- Accept CaptionGenerateRequest body
- Create operation_id (uuid4), asyncio.Queue
- Run `_run_caption_batch()` in background task (same pattern as import_.py)
- `_run_caption_batch` iterates images, calls `caption_image_for_project()` via `run_in_executor` (ONNX is blocking — Pitfall 4), calls `save_caption()`, sends SSE progress events
- Return CaptionStarted with operation_id

`GET /{op_id}/events` — SSE stream for generation progress:
- Mirror the import events pattern exactly (EventSourceResponse, None sentinel)

**4. Register router in `klippbok/api/app.py`:**
- Import captions router
- Add `app.include_router(captions_router, prefix="/api/v1")` before StaticFiles mount
- Add caption _tasks cancellation to lifespan shutdown (matching import/upscale pattern)
