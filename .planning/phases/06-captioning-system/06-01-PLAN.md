  <name>Task 1: Create WD Tagger v3 ONNX module and dependency group</name>
  <files>klippbok/caption/wd_tagger.py, pyproject.toml</files>
  <action>
Create `klippbok/caption/wd_tagger.py` following the exact reference implementation from SmilingWolf's app.py (documented in 06-RESEARCH.md Pattern 1 and Pattern 2).

The module MUST contain:

1. `prepare_image(image: Image.Image, model_target_size: int) -> np.ndarray`:
   - Composite RGBA onto white background (handles PNG transparency)
   - Pad to square with white fill (preserves aspect ratio)
   - Resize to model_target_size using BICUBIC (448 for ViT, but extract from model shape)
   - Convert to float32 numpy array
   - Reverse channel order RGB -> BGR (model trained on BGR)
   - Add batch dimension [1, H, W, C] (NHWC format)

2. `_get_tagger()` cached with `@lru_cache(maxsize=1)`:
   - Lazy-import onnxruntime, pandas, huggingface_hub inside the function
   - On ImportError, raise with helpful message pointing to `pip install 'klippbok[tagger]'`
   - Download model.onnx and selected_tags.csv from `SmilingWolf/wd-vit-tagger-v3` via `hf_hub_download`
   - Parse selected_tags.csv with pandas to get tag_names, general_indexes (category==0), character_indexes (category==4)
   - Create `rt.InferenceSession(model_path)`
   - Extract target_size from `model.get_inputs()[0].shape` (do NOT hardcode 448)
   - Return tuple: (model, tag_names, general_indexes, character_indexes, target_size)

3. `tag_image_booru(image_path: Path, general_threshold: float = 0.35, character_threshold: float = 0.85) -> tuple[list[str], list[str]]`:
   - Open image with Pillow
   - Call prepare_image with the extracted target_size
   - Run ONNX inference
   - Filter general tags above general_threshold, sort by score descending
   - Filter character tags above character_threshold, sort by score descending
   - Escape parentheses in tag names (booru convention): `(` -> `\(`, `)` -> `\)`
   - Return (general_tags, character_tags)

Module constants:
- MODEL_REPO = "SmilingWolf/wd-vit-tagger-v3"
- MODEL_FILENAME = "model.onnx"
- LABEL_FILENAME = "selected_tags.csv"
- GENERAL_THRESHOLD = 0.35
- CHARACTER_THRESHOLD = 0.85

In `pyproject.toml`, add a new `[tagger]` optional dependency group:

