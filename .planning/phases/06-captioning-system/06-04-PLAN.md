**1. Add batch functions to `klippbok/services/caption_service.py`:**

`batch_add_tag(tag: str, manifest: dict, project_dir: Path, image_ids: list[str] | None = None) -> int`:
- Iterate images in manifest (filter by image_ids if provided)
- For each entry with a caption: if tag not already present (case-insensitive check), append ", {tag}"
- Call `save_caption()` for each modified entry (writes sidecar + updates manifest)
- Return count of modified captions

`batch_remove_tag(tag: str, manifest: dict, project_dir: Path, image_ids: list[str] | None = None) -> int`:
- For each entry: split caption by ", ", filter out the tag (case-insensitive), rejoin with ", "
- Call `save_caption()` for each modified entry
- Return count of modified captions

`batch_replace_tag(old_tag: str, new_tag: str, manifest: dict, project_dir: Path, image_ids: list[str] | None = None) -> int`:
- For each entry: split caption by ", ", replace old_tag with new_tag (case-insensitive match), rejoin
- Call `save_caption()` for each modified entry
- Return count of modified captions

`batch_prepend_trigger(trigger: str, manifest: dict, project_dir: Path, image_ids: list[str] | None = None) -> int`:
- Reuse `_prepend_anchor()` from `klippbok.caption.captioner`
- For each entry with a caption: apply `_prepend_anchor(caption, trigger)`
- Call `save_caption()` for each modified entry
- Return count of modified captions

- Accept CaptionBatchRequest
