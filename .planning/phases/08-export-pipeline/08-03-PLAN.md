       - `ExportStartRequest(BaseModel)`: trainer (str), repeats (int), trigger_word (str), class_name (str), concept_name (str), output_path (str)

    3. `GET /defaults` — returns export defaults from `get_export_defaults(project_dir)` including candidate count

       - Builds ExportConfig from request body + project_dir
       - Calls `perform_export()` in `run_in_executor` with progress callback that puts `export_progress` events on queue
       - On success: puts `export_done` event with result data
       - On error: puts `export_error` event with message
       - Always puts `None` sentinel

    6. `GET /{op_id}/events` — SSE endpoint using `_sse_generator(queue)` pattern from cleanup.py. Event names: `export_progress`, `export_done`, `export_error`

    7. `POST /{op_id}/cancel` — cancels the export task if running
