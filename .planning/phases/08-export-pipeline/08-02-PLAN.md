  <name>Task 1: OneTrainer detection and subprocess management</name>
  <files>klippbok/services/onetrainer_service.py, tests/test_onetrainer_service.py</files>
  <behavior>
    - detect_onetrainer(configured_path=None): checks configured path first, then common paths list; validates venv/Scripts/python.exe + scripts/train.py exist; returns Path or None
    - _ONETRAINER_COMMON_PATHS: patchable module-level list (mirrors _SEEDVR2_COMMON_PATHS pattern)
    - launch_onetrainer_headless(ot_root, preset_path, queue, op_id): spawns Popen with ot venv python + train.py --config-path, starts stdout reader thread, stores in _ot_procs
    - launch_onetrainer_gui(ot_root, preset_path): spawns detached Popen with train_ui.py, no stdout capture needed
    - stop_onetrainer(op_id): terminates process gracefully, returns bool
    - is_training_active(): returns True if any _ot_procs entry has running process
    - parse_training_output(line): extracts epoch/step progress from tqdm-style output, returns dict or None
    - Error patterns: OOM_PATTERNS, FILE_NOT_FOUND, CUDA_ERROR as module constants
  </behavior>
  <action>
    Create `klippbok/services/onetrainer_service.py`:

    1. Module-level constants:
       - `_ONETRAINER_COMMON_PATHS`: list of common install paths (C:\GenAI\Data\Packages\OneTrainer, C:\OneTrainer, ~/OneTrainer, ~/GenAI/Data/Packages/OneTrainer)
       - `OOM_PATTERNS = ["OutOfMemoryError", "CUDA out of memory", "out of memory"]`
       - `FILE_NOT_FOUND_PATTERNS = ["No such file or directory", "FileNotFoundError"]`
       - `CUDA_ERROR_PATTERNS = ["CUDA error", "CUDA initialization"]`
       - `_ot_procs: dict[str, subprocess.Popen] = {}`

    2. `detect_onetrainer(configured_path: str | None = None) -> Path | None`:
       - Build candidate list: configured_path first, then _ONETRAINER_COMMON_PATHS
       - For each: check `candidate / "venv" / "Scripts" / "python.exe"` and `candidate / "scripts" / "train.py"` both exist
       - Return first match or None

    3. `launch_onetrainer_headless(ot_root: Path, preset_path: Path, queue: asyncio.Queue, op_id: str) -> None`:
       - Build cmd: [venv python, scripts/train.py, --config-path, preset_path]
       - Popen with stdout=PIPE, stderr=STDOUT, text=True, PYTHONUNBUFFERED=1, cwd=ot_root
       - Start daemon thread `_ot_stdout_reader(proc, queue, loop, op_id)` that reads lines, parses progress, checks error patterns, puts events on queue
       - Store proc in `_ot_procs[op_id]`

    4. `_ot_stdout_reader(proc, queue, loop, op_id)`: reads stdout line by line, strips ANSI codes, parses for epoch pattern `Epoch\s+(\d+)/(\d+)`, detects error patterns, puts training_progress/training_error/training_done events on queue via `loop.call_soon_threadsafe`

    5. `launch_onetrainer_gui(ot_root: Path, preset_path: Path | None = None) -> None`: Popen detached with train_ui.py, no tracking needed

    6. `stop_onetrainer(op_id: str) -> bool`: terminate proc, return True if found

    7. `is_training_active() -> bool`: check any proc in _ot_procs is still running

    8. `parse_training_output(line: str) -> dict | None`: regex for epoch/step patterns, returns {"epoch": N, "total_epochs": M} or None

    Write tests for: detect_onetrainer (mock paths), parse_training_output (various line formats), error pattern detection. Use monkeypatch for _ONETRAINER_COMMON_PATHS.
  </action>
