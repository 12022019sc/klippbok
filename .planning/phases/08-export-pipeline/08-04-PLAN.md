  <name>Task 1: Training API endpoints and settings extension</name>
  <files>klippbok/api/routers/export.py, klippbok/api/routers/settings.py</files>
  <action>
    Extend export router with training endpoints and settings router with tool path management.

    **Export router additions** (add to existing `klippbok/api/routers/export.py`):

    1. `GET /train/status` — returns OneTrainer detection status + training active status + GPU VRAM usage:
       ```python
       {
           "onetrainer_detected": bool,
           "onetrainer_path": str | None,
           "training_active": bool,
           "gpu_vram_used_mb": int | None,
           "gpu_busy": bool
       }
       ```

    2. `POST /train/start` — request body: `TrainStartRequest(preset_path: str, base_model_path: str | None, lora_rank: int = 64, lora_alpha: int = 64, epochs: int = 7, batch_size: int = 2, learning_rate: float = 1.0, resolution: int = 768)`.
       - Detect OneTrainer (from global config or common paths)
       - If not found: return 400 "OneTrainer not configured"
       - Read preset template from OneTrainer install, substitute: concept_file_name, output_model_destination, base_model_name (if provided), lora_rank, lora_alpha, epochs, batch_size, learning_rate, resolution
       - Write modified preset to export dir as `training_preset_active.json`
       - Create op_id, queue, launch headless training
       - Return `{"op_id": op_id}`

    3. `GET /train/{op_id}/events` — SSE endpoint for training progress. Event names: `training_progress` (epoch/total), `training_error` (message + log snippet), `training_done` (lora_path, epochs, duration)

    4. `POST /train/{op_id}/stop` — calls stop_onetrainer(op_id), returns status

    5. `POST /train/launch-gui` — launches OneTrainer GUI (detached, no tracking), returns status

    6. `GET /train/models` — scans model directory (from global config `onetrainer.model_dir`) for .safetensors and .ckpt files, organized by subfolder. Returns list of `{"path": str, "name": str, "subfolder": str}`. Returns empty list if model_dir not configured.

    **Settings router additions** (add to existing `klippbok/api/routers/settings.py`):

    7. `GET /settings/tools` — returns `{"onetrainer_path": str|None, "model_dir": str|None}` from global config

    8. `PUT /settings/tools` — accepts `ToolSettingsUpdate(onetrainer_path: str | None, model_dir: str | None)`, validates paths exist if provided, saves to global config under `onetrainer` key. Returns updated values.
  </action>
