**B. Create klippbok/services/crop_service.py** with module-level stateless functions (project decision SVC-01):
- `apply_crop(source_path: Path, left: int, top: int, width: int, height: int, rotation: int, flip_h: bool, flip_v: bool, target_width: int, target_height: int, output_path: Path) -> Path`
  - Open with Pillow, convert to RGB (handle RGBA/CMYK)
  - Apply rotation FIRST (0/90/180/270 using Image.Transpose constants -- NOT Image.ANTIALIAS which was removed in Pillow 10)
  - Apply flip (FLIP_LEFT_RIGHT, FLIP_TOP_BOTTOM)
  - Crop to (left, top, left+width, top+height)
  - Resize to (target_width, target_height) with Image.Resampling.LANCZOS
  - Save to output_path, return output_path
- `apply_crops_batch(crops: list[CropApplyRequest], project_dir: Path) -> list[CropApplyResult]`
  - Calls apply_crop for each item. Output path: `{project_dir}/.klippbok/crops/{stem}_{bucket_w}x{bucket_h}{ext}`
  - Creates output directory if needed
  - Returns list of results with success/error per image

**C. Create klippbok/image/autocrop.py:**
- `auto_crop_image(image_path: Path, buckets: list[tuple[int, int]]) -> tuple[int, int, int, int]`
  - Uses MediaPipe legacy `mp.solutions.pose.Pose(static_image_mode=True, min_detection_confidence=0.5)` API (bundles model, no download needed -- per RESEARCH.md Pitfall 6)
  - Read image with PIL, convert to RGB numpy array
  - Run pose detection. If landmarks found: derive bounding box from all 33 landmarks (min/max of x*width, y*height), add 10% padding, clamp to image bounds
  - Call `assign_to_bucket` on bbox dimensions to find nearest bucket ratio
  - Expand bbox to match bucket AR while keeping it centered on the detected subject and within image bounds
  - If no landmarks detected: call `_center_crop(img_width, img_height, buckets)` which picks the largest bucket that fits and centers the crop
- `_center_crop(img_width: int, img_height: int, buckets: list[tuple[int, int]]) -> tuple[int, int, int, int]`
  - Find the bucket whose AR is closest to the image AR (reuse assign_to_bucket)
  - Compute the largest crop area at that AR that fits within the image
  - Center it: left = (img_width - crop_width) // 2, top = (img_height - crop_height) // 2
- `_fit_crop_to_bucket(bbox_left, bbox_top, bbox_w, bbox_h, bucket, img_w, img_h) -> tuple[int, int, int, int]`
  - Expand or contract the bbox to match bucket[0]/bucket[1] aspect ratio
  - Keep the expansion centered on the original bbox center
  - Clamp to image bounds

```python
class CropApplyItem(BaseModel):
    image_id: str
    left: int
    top: int
    width: int
    height: int
    rotation: int = 0      # 0, 90, 180, 270
    flip_h: bool = False
    flip_v: bool = False
    target_width: int
    target_height: int

class CropApplyRequest(BaseModel):
    crops: list[CropApplyItem]

class CropApplyResult(BaseModel):
    image_id: str
    success: bool
    output_path: str | None = None
    error: str | None = None

class AutoCropRequest(BaseModel):
    image_ids: list[str]
    bucket_size: int = 1024
    allow_non_square: bool = True

class AutoCropResult(BaseModel):
    image_id: str
    left: int
    top: int
    width: int
    height: int
    target_bucket: tuple[int, int]
    detection_type: str     # "pose" | "center"

class UpscaleRequest(BaseModel):
    image_ids: list[str]
    upscaler: str = "seedvr2"   # "seedvr2" | "nmkd_siax"
    scale_factor: int = 2

class UpscaleProgress(BaseModel):
    operation_id: str
    current: int
    total: int
    message: str
    status: str     # "running" | "complete" | "error"
```
