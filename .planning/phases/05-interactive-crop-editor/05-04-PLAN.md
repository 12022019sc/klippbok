**A. Create useUpscaleEvents.ts** -- Clone of useImportEvents.ts adapted for upscale:
- Takes `operationId: string | null` as parameter
- Creates `EventSource` to `/api/v1/upscale/${operationId}/events` when operationId is non-null
- Listens for named events: "progress", "done", "upscale_error"
- Returns `{ current: number, total: number, message: string, status: string | null, isComplete: boolean, error: string | null }`
- On "progress": update current/total/message
- On "done": set isComplete=true, close EventSource
- On "upscale_error": set error message, close EventSource
- Cleanup: close EventSource on unmount or operationId change

**B. Create UpscaleStep.tsx:**

Props: `{ selectedImageIds: string[], onComplete: () => void, onSkip: () => void }`

Layout:
1. **Header**: "Step 1: Upscale Images (Optional)"
2. **Upscaler status**: On mount, fetch `GET /api/v1/upscale/status` to check availability. Show:
   - If SeedVR2 available: green indicator "SeedVR2 found at {path}"
   - If not available: yellow warning "SeedVR2 not found. Configure in Settings or skip this step."
   - Same for NMKD-Siax
3. **Controls** (only if at least one upscaler available):
   - Upscaler dropdown: `<select>` with available options (SeedVR2 / NMKD-Siax). Only show options that are detected as available.
   - Scale factor dropdown: `<select>` with 2x (default), 4x options
   - "Start Upscaling" button -- POST to `/api/v1/upscale/start` with selected settings
4. **Progress** (shown after upscale starts):
   - Use `useUpscaleEvents(operationId)` hook
   - Progress bar: same style as import progress bar (reuse CSS classes `.import-progress-bar-track` / `.import-progress-bar-fill`)

   - On error: show error message with "Retry" button
