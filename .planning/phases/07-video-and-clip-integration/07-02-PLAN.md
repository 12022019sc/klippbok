Compares each item against all concept reference embeddings. Returns TriageResult per item with: item_path, best_score, matches (list of concept+score), classification (match/borderline/no_match based on threshold and borderline range = threshold-0.1). Persists to triage_manifest.json if output_path given. Cache CLIPEmbedder in module-level `_embedder` variable (lazy init on first call, per research pitfall #1).

    Create `klippbok/api/routers/triage.py` following the SSE pattern:

    **CLIP Triage Endpoints:**

    1. `POST /triage/run/start` — Accepts TriageRunRequest (threshold: float = 0.70, item_ids: list[str] | None (None = all items), concepts_dir: str | None). Resolves item paths from project manifest. Creates asyncio.Queue + Task calling _run_triage(). Returns operation_id.

    2. `GET /triage/run/{op_id}/events` — SSE stream. Events: `triage_progress` (current, total, message), `triage_error`. Sentinel None.

    3. `POST /triage/run/{op_id}/cancel` — Cancel triage task.

    4. `GET /triage/results` — Returns persisted triage results from triage_manifest.json. Returns empty list if no manifest exists.

    **Concept Management Endpoints:**

    5. `GET /triage/concepts` — Returns list of concept references from project concepts/ dir via list_concepts().

    6. `POST /triage/concepts` — Accepts AddConceptRequest (image_id: str, category: str). Resolves image path from image_id, calls add_concept_reference(). Returns created ConceptReference.

    7. `POST /triage/concepts/upload` — Accepts UploadFile + category form field. Saves to concepts/{category}/ dir. Returns ConceptReference.

    **Face Embedding Endpoints:**

    8. `POST /triage/face/start` — Accepts FaceRunRequest (item_ids: list[str] | None). Creates background task for compute_face_embeddings + cluster_face_embeddings. Returns operation_id.

    9. `GET /triage/face/{op_id}/events` — SSE stream. Events: `face_progress` (current, total, eta_seconds, message), `face_error`. ETA computed from elapsed time and items remaining.

    10. `POST /triage/face/{op_id}/cancel` — Cancel face embedding task.

    11. `GET /triage/face/clusters` — Returns current face clusters. Stored in module-level `_face_clusters` dict keyed by project_dir.

    12. `POST /triage/face/clusters/{cluster_id}/name` — Accepts NameClusterRequest (name: str). Sets cluster suggested_name. When confirmed=true, creates concept reference from cluster's primary_reference.

    **Health Endpoint:**

    13. `GET /triage/health` — Returns { clip_available: bool, insightface_available: bool, clip_model_loaded: bool }.

    **Pydantic models** at top of router:
    - TriageRunRequest, AddConceptRequest, FaceRunRequest, NameClusterRequest
    - TriageResultResponse, ConceptResponse, FaceClusterResponse, HealthResponse

    **_run_triage async:** Run run_triage in executor (CPU-bound CLIP). Progress callback puts events into queue. Wrap in try/except/finally with None sentinel.

    **_run_face async:** Run compute_face_embeddings in executor, then cluster_face_embeddings. Two-stage progress: embedding phase then clustering phase.

    **Register router** in `klippbok/api/app.py`:
    - Add triage_router import and include_router call
    - Add triage _tasks and face _tasks to lifespan shutdown

    Tests use FastAPI TestClient. Mock triage_service and face_service functions.
