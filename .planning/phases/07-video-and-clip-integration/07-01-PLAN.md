  </behavior>
  <action>
    Create `klippbok/api/routers/video.py` following the exact SSE pattern from import_.py:

    **Endpoints:**

    1. `POST /video/ingest/start` — Accepts IngestRequest (video_path or directory_path, optional config overrides: fps, resolution, threshold, max_frames). Creates asyncio.Queue + asyncio.Task calling `_run_ingest()`. Returns `{"operation_id": op_id}`.

    2. `GET /video/ingest/{op_id}/events` — SSE stream. Events named `ingest_progress` (stage, current, total, message) and `ingest_error`. Sentinel None ends stream.

    3. `POST /video/ingest/{op_id}/cancel` — Cancel ingest task. Returns `{"cancelled": true}`.

    4. `GET /video/scan` — Synchronous. Calls scan_project_videos(project_dir). Returns scan report as JSON (list of VideoMetadata dicts with fps, duration, width, height, codec, frame_count, validation issues).

    5. `POST /video/extract/start` — Accepts ExtractRequest (clips_dir, output_dir, frames_per_clip). Creates background task. Returns operation_id.

    6. `GET /video/extract/{op_id}/events` — SSE stream for extract progress. Events named `extract_progress`.

    7. `POST /video/extract/{op_id}/cancel` — Cancel extract task.

    8. `GET /video/clips` — Returns list of video clips in project with metadata (id, relative_path, thumbnail_url, duration, fps, width, height, frame_count). Generate video thumbnails on the fly, cache them. ID = SHA256[:16] of relative_path.

    9. `GET /video/clips/{clip_id}/thumbnail` — Serve cached video thumbnail JPEG.

    **Pydantic models** (define at top of router file):
    - IngestRequest: video_path (str), directory_path (str | None), fps (int = 16), resolution (int = 720), threshold (float = 27.0), max_frames (int | None = None)
    - ExtractRequest: frames_per_clip (int = 1)
    - IngestStarted / ExtractStarted: operation_id (str)
    - VideoClipItem: id, relative_path, thumbnail_url, duration, fps, width, height, frame_count
    - ScanResultItem: filename, width, height, fps, duration, codec, frame_count, issues (list[str])

    **_run_ingest async function:** Run ingest_video in executor with progress_callback that puts IngestProgressEvent into queue. Wrap in try/except: on error put ingest_error event, always put None sentinel in finally.

    **Register router** in `klippbok/api/app.py`:
    - Import video router
    - Add `app.include_router(video_router, prefix="/api/v1")` BEFORE StaticFiles mount
    - Add video _tasks to lifespan shutdown cancellation

    **IngestRequest smart defaults per locked decision:** 16fps, 720p, auto frames with Advanced toggle on frontend.

    Tests use FastAPI TestClient with httpx. Mock video_service functions. Test that endpoints return correct status codes and response shapes.
