<objective>
Fix apply_vlm_pipeline step ordering so VLM artifact stripping runs before anchor
word injection. Add test covering the anchor + preamble combination.

Purpose: Currently, anchor injection runs first. A preamble like "Here is a
caption: ..." becomes "Luna, here is a caption: ..." after anchor prepend. The
^-anchored regex patterns in _strip_vlm_artifacts no longer match at position 0,
so the preamble survives post-processing. Reordering strips the preamble first
(clean text), then prepends the anchor (correct output).

Output: Corrected pipeline.py, one new test in test_caption_pipeline.py.
</objective>
