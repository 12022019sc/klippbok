# Phase 6.2 Plan 01: Caption Mode Foundation Summary

Caption mode system foundation with 5 universal modes, updated Pydantic models, post-processing pipelines, and rewritten prompt templates.

## What Was Built

### CaptionMode Type and Model Updates

Replaced the old `use_case` (character/style/motion/object) axis with a new `caption_mode` axis covering 5 universal modes:

- `booru_tags` — comma-separated tags (SD1.5 LoRA)
- `context_only_tags` — tags excluding physical appearance (Character LoRA, default)
- `context_only_natural` — NL excluding physical appearance (Character LoRA)
- `descriptive` — detailed natural language (SDXL/Flux)
- `straightforward` — factual NL, no speculation (SDXL/Flux)

**`CaptionConfig`**: `use_case` removed, `caption_mode` + `max_tokens` added. `extra="forbid"` enforces the removal hard.

**`CaptionGenerateRequest`**: `style` removed, `caption_mode: str | None` added.

**`CaptionProviderConfig`**: `caption_mode` + `max_tokens` added.

**`ModelProfile`**: `default_token_budget: int = 150` added. Built-in profiles: SD15=75, SDXL=150, Flux=225, Pony=75.

### pipeline.py (new module)

Pure function post-processing pipelines:

```python
apply_vlm_pipeline(caption, anchor_word, token_budget, caption_mode) -> str
apply_joycaption_pipeline(caption, anchor_word, token_budget, caption_mode, appearance_blacklist) -> str
DEFAULT_APPEARANCE_BLACKLIST  # 52 curated appearance tag entries
```

**VLM pipeline:** trigger injection → artifact stripping → token budget trimming

**JoyCaption pipeline:** prefix strip → noise blacklist → dedup → appearance filter (context_only modes only) → trigger injection → token budget trimming

Key helper functions: `_count_tokens_approx`, `_strip_vlm_artifacts`, `_strip_joycaption_prefixes`, `_filter_appearance_tags`, `_dedup_tags`, `_trim_to_budget`, `_normalize_tag`, `_tag_is_appearance`, `_prepend_anchor`.

### prompts.py (rewritten)

5 image and 5 video prompt templates keyed by `caption_mode`. Old use_case templates removed. `_fill_prompt` keeps `{anchor_line}` and `{secondary_line}` injection (simplified - `{subject}` and `{style_anchor_line}` removed). `get_image_prompt` and `get_video_prompt` now accept `caption_mode` (fallback to `context_only_tags`).
