**Create `klippbok/image/probe.py`**: Image metadata extraction using Pillow.

```python
def probe_image(path: Path) -> ImageMetadata:
    """Extract metadata from an image file.

    Uses Pillow's Image.open() + .verify() for corruption detection,
    then re-opens for metadata extraction (verify() closes the file).

    Args:
        path: Path to the image file.

    Returns:
        ImageMetadata with all fields populated.
        If the file is corrupt, returns ImageMetadata with is_corrupt=True
        and zero dimensions.

    Raises:
        ImageProbeError: If the file doesn't exist or can't be opened at all.
    """
```

Implementation details:
1. Check path.exists() -- raise ImageProbeError if not
2. Try `Image.open(path)` then `.verify()` in a try/except block
3. If verify fails: return `ImageMetadata(path=path, width=0, height=0, format="unknown", color_mode="unknown", is_corrupt=True, file_size=path.stat().st_size)`
4. Re-open the image (verify closes it): `img = Image.open(path)`
5. Extract: `img.width`, `img.height`, `img.format.lower()` (PIL returns "PNG" -> "png", "JPEG" -> "jpeg"), `img.mode` for color_mode, `"A" in img.mode` for has_alpha
6. Get file_size from `path.stat().st_size`
7. Handle the edge case where `img.format` is None (some PIL modes) -- treat as "unknown" format

Wrap Pillow import in a try/except for optional dependency handling:
```python
try:
    from PIL import Image
except ImportError:
    raise ImageError(
        "Pillow is required for image processing. "
        "Install with: pip install klippbok[image]"
    )
```

Do this import at module level so the error surfaces early, not buried in a function call.

**Create `klippbok/image/validate.py`**: Accumulative image validation.

```python
def validate_image(
    metadata: ImageMetadata,
    min_resolution: int = 256,
    max_resolution: int = 4096,
) -> ImageValidation:
    """Validate an image against structural requirements.

    Collects ALL issues (accumulative, never fail-fast).
    Phase 1 checks: format, corruption, dimensions, color mode.
    Bucket-aware validation deferred to Phase 3 (needs model profiles).

    Args:
        metadata: Probed image metadata.
        min_resolution: Minimum dimension (width or height) in pixels.
        max_resolution: Maximum dimension in pixels.

    Returns:
        ImageValidation with all found issues.
    """
```

Validation checks (in this order):
1. **Corruption**: If `metadata.is_corrupt`, append `IMAGE_CORRUPT` ERROR with message "Image file is corrupt or truncated. Re-download or re-export this file."
2. **Format**: If `metadata.format not in SUPPORTED_IMAGE_FORMATS`, append `IMAGE_FORMAT_UNSUPPORTED` ERROR with message listing supported formats.
3. **Dimensions below min**: If `metadata.width < min_resolution or metadata.height < min_resolution`, append `IMAGE_BELOW_MIN_RESOLUTION` ERROR with actual vs expected.
4. **RGBA**: If `metadata.color_mode == "RGBA"` or `metadata.has_alpha`, append `IMAGE_RGBA_CONVERSION` WARNING with message "Image has alpha channel (RGBA). Will be flattened to RGB with white background during export."

Each ValidationIssue must include: code, severity, message (with fix hint), field, actual, expected. Follow the exact pattern in `video/validate.py`.
