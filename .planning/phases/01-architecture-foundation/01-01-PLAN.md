Create `klippbok/services/` package:

**`klippbok/services/__init__.py`**: Public API with `__all__` re-exporting key functions from both services. Follow the pattern in `klippbok/video/__init__.py` with categorized imports.

**`klippbok/services/dataset_service.py`**: Stateless functions extracted from `dataset/__main__.py`:

1. `validate(config: KlippbokDataConfig, config_dir: Path, quality: bool = False, duplicates: bool = False) -> DatasetReport` -- Extracts the logic from `cmd_validate` lines 170-205: applies CLI quality/duplicate overrides to config, calls `validate_all()`, returns the report. Does NOT handle output formatting (that stays in CLI).

2. `organize(source_dir: Path, output_dir: Path, layout: OrganizeLayout, config: KlippbokDataConfig | None = None, copy: bool = True, include_warnings: bool = True, dry_run: bool = False, trainers: list[str] | None = None, concepts: list[str] | None = None) -> OrganizeResult` -- Extracts the logic from `cmd_organize` lines 307-365: concept resolution, config construction, delegates to `organize_dataset()`. Returns the result.

3. `preview_bucketing(report: DatasetReport, min_bucket_size: int) -> BucketPreview` -- Thin wrapper around `bucketing.preview_bucketing()` for consistent service API.

All functions are module-level (no class). All accept their inputs and return results. No print statements, no sys.exit, no argparse references.

**`klippbok/services/project_service.py`**: Project manifest management:

1. `save_manifest(project_dir: Path, samples: list[dict], version: str = "1") -> Path` -- Writes `.klippbok/manifest.json` inside `project_dir`. Creates `.klippbok/` directory if it doesn't exist. Manifest JSON structure:
   ```json
   {
     "version": "1",
     "created": "ISO8601 timestamp",
     "updated": "ISO8601 timestamp",
     "samples": [...]
   }
   ```
   Uses relative paths for portability. Returns the path to the written manifest.

2. `load_manifest(project_dir: Path) -> dict | None` -- Reads `.klippbok/manifest.json` if it exists, returns parsed dict. Returns None if no manifest found. Validates that `version` field is present.

3. `manifest_exists(project_dir: Path) -> bool` -- Quick check.

4. `sample_to_manifest_entry(sample: SamplePair, project_dir: Path) -> dict` -- Converts a SamplePair to a manifest dict entry with relative paths, type, dimensions, status, and serialized issues.

**Tests**:
- `tests/test_dataset_service.py`: Test that `validate()` returns a valid DatasetReport when given a config pointing at a test fixture directory. Test that `organize()` returns an OrganizeResult. Test that quality/duplicate overrides are applied to config.
- `tests/test_project_service.py`: Test save/load roundtrip, test manifest_exists, test sample_to_manifest_entry serialization, test that `.klippbok/` directory is created, test that relative paths are stored.

Use `tmp_path` pytest fixture for filesystem tests. Do NOT mock filesystem calls -- use real temp directories.
