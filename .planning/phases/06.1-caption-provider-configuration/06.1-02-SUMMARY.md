# Phase 6.1 Plan 02: Caption Provider Frontend UI Summary

**One-liner:** Full CaptionPage workspace with collapsible provider config, scrollable thumbnail strip, batch tag operations, and inline caption editor — plus NavBar Caption item and GalleryPage cleanup.

## What Was Built

### Task 1: CaptionPage and caption components

**frontend/src/pages/CaptionPage.tsx** (new, 185 lines)
- Loads provider config via `useQuery(['caption-config'], GET /api/v1/captions/config)`
- Loads images via `useImages()` hook
- Loads settings via `useQuery(['settings'], GET /api/v1/settings/)` for trigger word
- State: `selectedImageId`, `captionOperationId`, `editingCaption`, `isGenerating`
- Reuses `useCaptionEvents(captionOperationId)` for SSE progress with toast updates
- Generate Captions button sends `POST /captions/generate` with `provider_preset` from config
- Caption textarea with Save (PATCH) and Reset buttons per selected image
- Invalidates `['images']` query on generation complete to refresh captions

**frontend/src/components/Caption/ProviderConfigSection.tsx** (new, 220 lines)
- Collapsible panel: collapsed shows "LM Studio — model-name" summary with expand arrow
- Provider dropdown: LM Studio | NanoGPT | Gemini | JoyCaption
- Model picker: `useQuery(['caption-models', provider, baseUrl])` with `staleTime: 30_000`
  - LM Studio: dropdown from API, text input fallback when list empty ("No model loaded")
  - NanoGPT: dropdown from API
  - Gemini: static list (gemini-2.5-flash, gemini-2.0-flash, gemini-1.5-flash, gemini-1.5-pro)
  - JoyCaption: path input only (no model dropdown)
- API key (masked password input with show/hide toggle): shown for nanogpt + gemini only
- Base URL input: LM Studio only
- JoyCaption path input: JoyCaption only
- Trigger word: always visible, saved to `PUT /api/v1/settings/` (anchor_word field)
- Advanced toggle (collapsed): custom prompt textarea
- Save button: two PUT calls (config + settings if trigger word changed)

**frontend/src/components/Caption/ThumbnailStrip.tsx** (new, 55 lines)
- Horizontal scrollable row with `scroll-snap-type: x mandatory`
- 80px tall thumbnails with filename label below (truncated at 16 chars)
- Click → `onSelect(imageId)`, selected item shows blue border ring

**frontend/src/components/Caption/BatchTagBar.tsx** (new, 130 lines)
- Add Tag: text input + "Add" button → `action="add_tag"`
- Remove Tag: text input + "Remove" button → `action="remove_tag"`
- Replace Tag: two inputs (from → to) + "Replace" button → `action="replace_tag"`
- Prepend Trigger: button with trigger word display → `action="prepend_trigger"`
- All ops call `POST /api/v1/captions/batch`; success/failure toasts via sonner
- Warning toast if prepend clicked with no trigger word set

**frontend/src/index.css** (modified — 350+ lines added)
- `.caption-page` flex column layout
- `.provider-config*` collapsible section with dark theme (bg: #1a1a2e, border: #334155)
- `.thumbnail-strip*` horizontal scroll with scroll-snap
- `.batch-tag-bar*` flex row with color-coded operation buttons (green/red/blue/indigo)
- `.caption-workspace` two-column grid (image preview + caption editor)
- `.caption-textarea` monospace, full height, resize vertical
- `.caption-generate-*` generate button and progress bar
