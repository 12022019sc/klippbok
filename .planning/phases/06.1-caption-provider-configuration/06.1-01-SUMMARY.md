# Phase 6.1 Plan 01: Caption Provider Backend Infrastructure Summary

**One-liner:** Atomic global config CRUD, JoyCaption subprocess detection, and lm_studio/nanogpt/gemini provider routing with 4 new REST endpoints.

## What Was Built

### Task 1: Global config service, JoyCaption detection, provider routing (TDD)

**klippbok/services/global_config_service.py** (new)
- `load_global_config() -> dict`: reads `~/.klippbok/config.json`, returns `{}` if absent or invalid JSON
- `save_global_config(config: dict) -> None`: creates directory, writes to temp file, `os.replace` atomically

**klippbok/caption/joycaption.py** (new)
- `_build_joycaption_paths()`: builds candidate list from common paths + `JOYCAPTION_PATH` env var
- `_JOYCAPTION_COMMON_PATHS`: module-level patchable list (same pattern as `_SEEDVR2_COMMON_PATHS`)
- `detect_joycaption() -> Path | None`: checks `venv/Scripts/python.exe` (Windows) and `venv/bin/python` (Linux)

**klippbok/services/caption_service.py** (modified)
- Added `build_vlm_config_from_global(provider, global_config, manifest) -> CaptionConfig`
- Maps `lm_studio` -> OpenAI provider with `api_key="lm-studio"`, base_url from config
- Maps `nanogpt` -> OpenAI provider with `https://nano-gpt.com/api/v1`, api_key from config
- Maps `gemini` -> Gemini provider, config.json key priority over `GEMINI_API_KEY` env var
- `joycaption` and unknown providers raise `ValueError` with helpful messages
- `anchor_word` from `manifest.get("anchor_word")`, `custom_prompt` from config

30 tests written and passing across 3 test files.

### Task 2: API endpoints for caption config and model listing

**klippbok/api/models.py** (modified)
- `CaptionProviderConfig`: Pydantic model for config CRUD (provider, base_url, api_keys, models, custom_prompt)
- `CaptionGenerateRequest.provider_preset`: new optional field; when set, overrides `provider`/`api_key`

**klippbok/api/routers/captions.py** (modified)
- `GET /config`: loads from `~/.klippbok/config.json`, returns `CaptionProviderConfig` with defaults
- `PUT /config`: merges into existing config, saves atomically, returns saved model
- `GET /models?provider=lm_studio`: LM Studio: `GET {base_url}/models`; NanoGPT: bearer auth API call; Gemini/JoyCaption: static lists
- `GET /health?provider=lm_studio`: LM Studio: 3s timeout probe; others: always healthy
- `_run_caption_batch`: now resolves `provider_preset` via `build_vlm_config_from_global` before falling back to legacy `provider`/`api_key` fields

All endpoints registered before `/{image_id}` PATCH (ROUTE-01 compliance).
