- Rewritten VideoPage with QuickProcess as the hero component and AdvancedPanel (collapsed) below
- Three-state QuickProcess flow: setup (video list + settings) -> processing (stage-aware progress) -> review (frame grid)
- FrameReviewGrid with toggle-select UX: all frames selected by default, clicking dims/crosses out deselected frames
- Confirm imports only selected frames via batch_import_images and invalidates TanStack Query cache
- Discard prompts user whether to also remove source videos from gallery
- Navigation state from Gallery pre-populates queued video paths in QuickProcess
- Added skippedVideos to useProcessEvents ProcessState for displaying skip warnings
