<objective>
Rewrite VideoPage.tsx as a multi-state component with Quick Process as the default view and existing Advanced tabs as a toggle. Implement the full Quick Process 3-state flow (setup -> processing -> review) with stage-aware progress and a frame review grid with toggle-select UX.

Purpose: The current VideoPage has disconnected Ingest/Scan/Extract tabs that don't flow into the gallery. This rewrite creates a unified Quick Process pipeline that automates scene detect -> split -> extract -> review -> confirm/import, making video processing feel like one connected flow.

Output: Rewritten VideoPage with QuickProcess, FrameReviewGrid, ProcessingProgress, and AdvancedPanel components.
</objective>

SSE events on GET /api/v1/video/process/{op_id}/events:
```typescript
// process_progress event data
{ operation_id: string, stage: string, current: number, total: number, message: string, status: "running" }
// process_done event data
{ operation_id: string, stage: "Complete", current: number, total: number, message: string, status: "complete",
  extracted_frames: Array<{video_path: string, frame_path: string}>,
  processed_video_paths: string[],
  skipped_videos?: Array<{path: string, reason: string}> }
```

POST /api/v1/video/process/confirm:
```typescript
// Request
{ video_paths: string[], frame_paths?: string[] }
// Response
{ imported: number, removed: number }
```

POST /api/v1/video/process/discard:
```typescript
// Request
{ frame_paths: string[], remove_videos?: boolean, video_paths?: string[] }
// Response
{ deleted: number }
```

GET /api/v1/video/process/frame?path={rel_path}:
  Returns image/png for frame thumbnail display
