<objective>
Enhance the video process backend pipeline to support scene detection + split for long videos, selective frame confirmation, enhanced discard with optional video entry removal, and cancel cleanup.

Purpose: The current _run_process only does direct frame extraction -- one frame per video regardless of length. Long raw videos (>=30s) need scene detection and splitting first to produce multiple clips, then extract one reference frame per clip. The confirm/discard endpoints also need enhancements for the frame review UX (selective import, optional video removal).

Output: Enhanced video.py router with multi-stage pipeline, updated confirm/discard endpoints, and comprehensive tests.
</objective>
