  <action>
    Create the `klippbok/api/` package with:

    **klippbok/api/__init__.py**: Empty init file.

    **klippbok/api/models.py**: Pydantic response models:
    - `ImageStatusResponse`: id (str, SHA256 of relative path truncated to 16 chars), relative_path (str), thumbnail_url (str, `/api/v1/images/{id}/thumbnail`), width (int), height (int), resolution_ok (bool -- True if image >= bucket dims i.e. downscale only), quality_pass (bool -- True if no blur detected), bucket (str | None, e.g. "768x512"), is_near_duplicate (bool), duplicate_group_id (str | None), caption (str | None).
    - `GalleryResponse`: total (int), images (list[ImageStatusResponse]).

    **klippbok/api/thumbnail.py**: Thumbnail generation with disk cache:
    - `THUMB_MAX_SIZE = (300, 300)` -- max dimensions; Pillow thumbnail() preserves aspect ratio.
    - `get_thumbnail(image_path: Path, cache_dir: Path) -> Path`: Hash full absolute path with SHA256[:16], check if `{cache_dir}/{hash}.jpg` exists. If not, open with Pillow, `img.convert("RGB")` (strip alpha for JPEG safety), `img.thumbnail(THUMB_MAX_SIZE, Image.LANCZOS)`, save as JPEG quality=85 optimize=True. Return the thumb_path.
    - Cache dir default: project_dir / ".klippbok" / "thumbnails".

    **klippbok/api/routers/__init__.py**: Empty init.

    **klippbok/api/routers/images.py**: FastAPI router with:
    - `router = APIRouter(prefix="/images", tags=["images"])`
    - State: Accept `project_dir` as app state (set during create_app via `app.state.project_dir`).
    - `GET /` (list images): Load manifest via `load_manifest(project_dir)`. Read `manifest["images"]` list. For each image entry, compute SHA256 ID from relative path, map manifest fields to ImageStatusResponse fields. resolution_ok = entry has no issue with code "IMAGE_UPSCALE_REQUIRED". quality_pass = entry has no issue with code "IMAGE_BLUR_DETECTED". bucket = entry.get("bucket"). is_near_duplicate = "near_duplicate_of" in entry. duplicate_group_id = entry.get("phash")[:8] if is_near_duplicate else None (cluster by similar phash prefix). Return GalleryResponse.
    - `GET /{image_id}/thumbnail`: Find the matching image entry by computing SHA256 of each entry's relative_path and comparing. Resolve to absolute path (project_dir / relative_path). Call `get_thumbnail(abs_path, cache_dir)`. Return `FileResponse(thumb_path, media_type="image/jpeg")`.
    - If manifest doesn't exist or has no "images" key, return empty GalleryResponse.

    **klippbok/api/app.py**: App factory:
    - `create_app(project_dir: Path | None = None) -> FastAPI`: Create FastAPI instance with title="klippbok". Store project_dir (default to Path.cwd()) on `app.state.project_dir`. Import and include images router with prefix="/api/v1". Mount StaticFiles AFTER routers (only if static dir exists): `app.mount("/", StaticFiles(directory=static_dir, html=True), name="spa")` where static_dir = `Path(__file__).parent / "static"`. CRITICAL: routers MUST be registered before StaticFiles mount.

    Important: Use `from fastapi import Request` to access `request.app.state.project_dir` in route handlers. Do NOT use global state.
