    **klippbok/api/models.py**: Add these models (append to existing file from Plan 01):
    - `ImportRequest(BaseModel)`: directory (str), recursive (bool = False).
    - `ImportStarted(BaseModel)`: operation_id (str).
    - `ImportProgress(BaseModel)`: operation_id (str), current (int), total (int), message (str), status (str -- "running" | "complete" | "error").
    - `SettingsResponse(BaseModel)`: project_dir (str), active_profile (str | None).
    - `SettingsUpdate(BaseModel)`: active_profile (str | None = None).

    **klippbok/api/routers/import_.py**: Import router:
    - `router = APIRouter(prefix="/import", tags=["import"])`
    - Module-level state: `_queues: dict[str, asyncio.Queue] = {}` and `_tasks: dict[str, asyncio.Task] = {}` for tracking active operations.
    - `POST /` (start import): Accept ImportRequest body. Generate op_id with `uuid.uuid4()`. Create an asyncio.Queue. Create asyncio.Task running `_run_import(request, queue, op_id, project_dir)`. Store queue and task in module dicts. Return ImportStarted(operation_id=op_id).
    - `GET /{op_id}/events` (SSE stream): Look up queue by op_id. If not found, raise 404. Use `EventSourceResponse` from sse-starlette. Generator yields events from queue. Each event is an ImportProgress serialized to JSON. When event has status="complete" or status="error", yield final event and break. Clean up: delete queue and task from module dicts.
    - `_run_import(request, queue, op_id, project_dir)` async function: This wraps the synchronous `batch_import_images` call. Since batch_import_images is synchronous and CPU-bound, run it in a thread via `asyncio.get_event_loop().run_in_executor(None, ...)`. BUT batch_import_images doesn't have progress callbacks yet. For Phase 4, implement a simpler approach:
      1. Use `discover_images` to get the file list first (put progress: "Discovering images...")
      2. Run `batch_import_images` synchronously in executor (put progress: "Importing {total} images...")
      3. When done, put the final "complete" event with summary from ImageImportReport
      4. On exception, put an "error" event with the error message
      5. Put `None` sentinel to signal stream end
    - NOTE: Fine-grained per-image progress would require refactoring batch_import_images to accept a callback. That's a future enhancement. For Phase 4, the SSE stream shows start/complete/error states.

    **klippbok/api/routers/settings.py**: Settings router:
    - `router = APIRouter(prefix="/settings", tags=["settings"])`
    - `GET /`: Return SettingsResponse with project_dir from app state, and active_profile read from project manifest or None.
    - `PUT /`: Accept SettingsUpdate. For Phase 4, this is a stub that returns the updated settings. Profile persistence will be wired in a future phase.

    **klippbok/api/app.py**: Update create_app to:
    - Import and register import_ and settings routers (with prefix="/api/v1").
    - Add a `lifespan` context manager that cancels all active import tasks on shutdown:
      ```python
      from contextlib import asynccontextmanager

      @asynccontextmanager
      async def lifespan(app: FastAPI):
          yield
          # Cancel active import tasks on shutdown
          from klippbok.api.routers.import_ import _tasks
          for task in _tasks.values():
              task.cancel()
      ```
    - Pass lifespan to FastAPI constructor: `FastAPI(title="klippbok", lifespan=lifespan)`.
