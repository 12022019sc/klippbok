<task type="auto">
  <name>Task 1: Build frontend and copy to static directory</name>
  <files>
    frontend/dist
    klippbok/api/static
  </files>
  <action>
    1. Build the React frontend for production:
       ```
       cd frontend && npm run build
       ```
       This produces `frontend/dist/` with index.html, assets, etc.

    2. Copy built output to FastAPI's static directory:
       ```
       rm -rf klippbok/api/static
       cp -r frontend/dist klippbok/api/static
       ```

    3. Verify the static directory has the expected files:
       ```
       ls klippbok/api/static/
       ```
       Should contain: index.html, assets/ directory with JS and CSS bundles.

    4. Add `klippbok/api/static/` to `.gitignore` -- built artifacts should not be committed:
       ```
       echo "klippbok/api/static/" >> .gitignore
       ```

    5. Test the combined server serves the SPA:
       - Start the server in background: `python -m klippbok.__main_serve__ &`
       - Curl the root to verify SPA is served: `curl -s http://localhost:8000/ | head -5` (should contain HTML with React root div)
       - Curl API endpoint: `curl -s http://localhost:8000/api/v1/images` (should return JSON)
       - Kill the background server

    Note: If there is no test project with imported images, create a temporary one for testing:
    - Create a temp directory with a few test images
    - Run batch_import_images against it to populate the manifest
    - Start the server pointing at that directory
  </action>
  <verify>
    Run: `ls klippbok/api/static/index.html` -- built SPA exists.
    Run: `python -c "from klippbok.api.app import create_app; app = create_app(); print('App serves SPA')"` -- app factory succeeds with static dir present.
  </verify>
  <done>
    Built React SPA exists in klippbok/api/static/. FastAPI serves it via StaticFiles mount.
  </done>
</task>
