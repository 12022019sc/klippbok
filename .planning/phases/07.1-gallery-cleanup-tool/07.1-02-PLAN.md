1. **Create `frontend/src/pages/CleanupPage.tsx`:**
   A dedicated cleanup page with three states: idle, scanning, review.

   **State management:**
   - `operationId: string | null` (local state for current scan)
   - Use `useCleanupEvents(operationId)` for SSE progress
   - Use `useAppStore` for cleanupResults, cleanupUnflaggedIds, cleanupAutoStart
   - `hasAutoStarted` ref to prevent double-start (per RESEARCH pitfall 5)

   **Auto-start behavior (locked decision):**
   - On mount, check `cleanupAutoStart` from appStore. If true, call `setCleanupAutoStart(false)` and trigger scan start.
   - Also check URL search params `?autostart=true` as fallback.
   - Use `hasAutoStarted` ref to prevent double-start.

   **Idle state (no scan running, no results):**
   - "Start Cleanup Scan" button
   - Brief description: "Scan all imported media to identify items without a clear human subject"

   **Scanning state (operationId set, not complete):**
   - Progress bar showing current/total from useCleanupEvents
   - Current item message text
   - "Cancel" button that POSTs to `/api/v1/cleanup/${operationId}/cancel`
   - As items are classified, accumulate results from SSE progress events (each event may include the latest classified item)

   **Review state (scan complete, results available):**
   - **Summary stats bar** at top: "{flaggedCount} flagged / {keptCount} kept / {total} total"
     - flaggedCount = results where label is "review" or "remove" AND not in cleanupUnflaggedIds
     - keptCount = results where label is "keep" OR in cleanupUnflaggedIds
   - **Thumbnail grid of flagged items only** (label="review" or "remove", not in cleanupUnflaggedIds)
     - Each thumbnail: `<img>` loading from `/api/v1/images/{item_id}/thumbnail`
     - Confidence score overlay (badge in corner, e.g., "0.42")
     - Label badge ("review" or "remove") with color coding (yellow for review, red for remove)
     - **Click handler**: `toggleCleanupUnflag(item_id)` — item disappears from grid (rescued)
   - **"Confirm Removal" button** (primary, prominent):
     - Collects item_paths of all remaining flagged items (not in cleanupUnflaggedIds)
     - POSTs to `/api/v1/cleanup/confirm` with `{ item_paths }`
     - On success: show toast via sonner ("X items moved to _review/"), call `clearCleanup()`, navigate to "/"
   - **"Re-scan" button** (secondary) to run again
   - **"Cancel" link** to go back without removing anything

   **Error handling:** Display error from useCleanupEvents if present, with retry button.

   **Start scan function:**
   ```typescript
   async function startScan() {
     const res = await fetch('/api/v1/cleanup/start', {
       method: 'POST',
       headers: { 'Content-Type': 'application/json' },
       body: JSON.stringify({})  // use defaults
     })
     const data = await res.json()
     setOperationId(data.operation_id)
   }
   ```

   When `useCleanupEvents.isComplete` becomes true and results are available, call `setCleanupResults(results)` to store in appStore.
