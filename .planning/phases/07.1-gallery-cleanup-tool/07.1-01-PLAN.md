   - `classify_items(item_paths: list[Path], project_dir: Path, positive_prompts: list[str] | None, negative_prompts: list[str] | None, clip_threshold: float, progress_callback: Callable[[int, int], None] | None) -> list[CleanupClassification]`: Encode ALL text prompts ONCE at start (anti-pattern avoidance). For video files (.mp4, .mov, .avi, .mkv, .webm), use `sample_clip_frames()` to sample 3 frames, classify each, use best score. Call progress_callback(current, total) after each item.

Return {"moved": count, "review_dir": str(_review/)}.

Create `klippbok/api/routers/cleanup.py` following the exact SSE pattern from `klippbok/api/routers/triage.py`:

1. **Module-level state:**
   ```python
   router = APIRouter(prefix="/cleanup", tags=["cleanup"])
   _cleanup_tasks: dict[str, asyncio.Task] = {}
   _cleanup_queues: dict[str, asyncio.Queue] = {}
   _cleanup_results: dict[str, list[dict]] = {}  # op_id -> classification results
   ```

2. **Request/Response models:**
   - `CleanupStartRequest(BaseModel)`: positive_prompts (list[str] | None = None), negative_prompts (list[str] | None = None), clip_threshold (float = 0.25)
   - `ConfirmRemovalRequest(BaseModel)`: item_paths (list[str])

3. **Background task:**
   - `_run_cleanup_bg(op_id, project_dir, positive_prompts, negative_prompts, clip_threshold)`: Load manifest to get all image/video paths. Call `classify_items()` with progress_callback that puts `ServerSentEvent(event="cleanup_progress")` on queue. On completion, store results in `_cleanup_results[op_id]`, emit `cleanup_done` event. On error, emit `cleanup_error`. Always put `None` sentinel.
   - Use `asyncio.get_event_loop().run_in_executor(None, ...)` for CPU-bound classify_items call. Inside the executor, use a thread-safe callback approach: the progress_callback should use `loop.call_soon_threadsafe(queue.put_nowait, event)`.

4. **SSE generator:** Reuse the exact `_sse_generator` pattern from triage.py (read from queue, yield events, clean up on sentinel/cancel).

5. **Endpoints:**
   - `POST /cleanup/start`: Generate uuid4 op_id, create queue, create asyncio.Task wrapping `_run_cleanup_bg`, return `{"operation_id": op_id}`
   - `GET /cleanup/{op_id}/events`: Return `EventSourceResponse(_sse_generator(...))`
   - `POST /cleanup/{op_id}/cancel`: Cancel the task, put error event on queue, return status
   - `POST /cleanup/confirm`: Call `confirm_removal()` from cleanup_service, return result
   - `GET /cleanup/results/{op_id}`: Return stored classification results from `_cleanup_results`

6. **Register in app.py:**
   - Import cleanup_router in `klippbok/api/app.py`
   - Add `app.include_router(cleanup_router, prefix="/api/v1")` BEFORE the StaticFiles mount (after video_router line)

7. **Lifespan cleanup:** Add `_cleanup_tasks` to the lifespan shutdown handler in app.py (same pattern as import/upscale/triage task cancellation).
