    - Auto-detect reference face from largest face cluster when config has no reference_embedding
    - Pipeline summary has correct funnel counts (total_scanned = input count, passed_quality = after floor, selected = target_count)
    - save_results writes CurationResult to .klippbok/curation_results.json
    - load_results reads it back and returns CurationResult
    - rediversify re-runs diversity selection with new pins/excludes, reusing cached scores

  <action>
1. Create `klippbok/curation/pipeline.py`:
   - `_auto_detect_reference(image_paths: list[Path], project_dir: Path) -> np.ndarray | None`:
     a. Call face_service.compute_face_embeddings for all image_paths.
     b. Call face_service.cluster_face_embeddings on results.
     c. Find largest cluster. Return the centroid embedding of that cluster.
     d. If no faces found, return None.

   - `run_curation(image_paths: list[Path], project_dir: Path, config: CurationConfig, progress_callback: Callable[[str, int, int], None] | None = None) -> CurationResult`:
     a. If config.reference_face_embedding is None and mode == "character", call _auto_detect_reference. Store embedding in config.
     b. Fire progress_callback("scoring", 0, total) at start.
     c. Call score_images(image_paths, config.mode, reference_embedding, scoring_progress_cb).
     d. Quality floor: sort by composite_score, compute numpy percentile at quality_floor_pct. Filter out images below cutoff.
     e. Fire progress_callback("selecting", 0, 1).
     f. Gather CLIP embeddings, pose vectors, face embeddings from scored images (use CLIPEmbedder.encode_images for CLIP, extract pose_vector from SignalScores, extract face embeddings from InsightFace -- store these during scoring as cached numpy arrays on a module-level dict keyed by op_id or pass through).
     g. Call select_diverse_subset with passed images, target_count, embeddings, pins, excludes.
     h. Compute PipelineSummary with funnel counts.
     i. Build CurationResult, save to disk, return it.

   - `rediversify(project_dir: Path, pinned_ids: list[str], excluded_ids: list[str], target_count: int | None = None) -> CurationResult`:
     a. Load existing results from disk.
     b. Re-extract embeddings for the scored pool (from cached scores).
     c. Call select_diverse_subset with new pins/excludes.
     d. Update result with new selected_ids, pinned_ids, excluded_ids. Update summary.
     e. Save and return.

   - `save_results(project_dir: Path, result: CurationResult) -> None`:
     Write result.model_dump_json(indent=2) to project_dir / ".klippbok" / "curation_results.json".

   - `load_results(project_dir: Path) -> CurationResult | None`:
     Read and parse. Return None if file doesn't exist.

   Note: Embeddings needed for diversity are collected during scoring. Store them in a module-level cache dict `_embedding_cache: dict[str, np.ndarray]` keyed by image_id during score_images, cleared on new run. The pipeline extracts them after scoring.

<task type="auto">
  <name>Task 2: Curation API router with SSE progress</name>
  <files>klippbok/api/routers/curation.py, klippbok/api/app.py, tests/test_curation_api.py</files>
  <action>
1. Create `klippbok/api/routers/curation.py` following cleanup.py SSE pattern exactly:
   - Module-level state: `_curation_tasks`, `_curation_queues`, `_curation_results` dicts.
   - Request models:
     - `CurationStartRequest(BaseModel)`: mode (str, default "character"), target_count (int | None, default None), quality_floor_pct (float, default 0.3), advanced settings optional.
     - `RediversifyRequest(BaseModel)`: pinned_ids (list[str]), excluded_ids (list[str]), target_count (int | None, default None).

   - `POST /curation/start` (status_code=202):
     a. Get project_dir from request.app.state.project_dir.
     b. Load image manifest, resolve image paths.
     c. Build CurationConfig from request body. If target_count is None, use get_target_count_default from settings/model profile.
     d. Create op_id, asyncio.Queue.
     e. Spawn background task: runs run_curation in executor with progress_callback that puts SSE events into queue. Thread-safe via loop.call_soon_threadsafe.
     f. SSE events: "curation_progress" (stage, current, total), "curation_done" (full result JSON), "curation_error" (error message).
     g. Return {"operation_id": op_id}.

   - `GET /curation/{op_id}/events`:
     SSE stream consuming from queue. None sentinel ends stream. Same pattern as cleanup.py.

   - `POST /curation/{op_id}/cancel`:
     Cancel the asyncio task, cleanup queue.

   - `GET /curation/results`:
     Call load_results(project_dir). Return 404 if None.

   - `POST /curation/rediversify`:
     Call rediversify(project_dir, pinned_ids, excluded_ids, target_count). Return updated CurationResult.

   - `POST /curation/apply`:
     Load results, return {"selected_ids": result.selected_ids}. Frontend uses these to set gallery selection.
