1. Create `klippbok/curation/scorer.py`:
   - Module-level singletons: `_pyiqa_model`, `_aesthetic_model`, `_aesthetic_preprocessor` with lazy-loading getters following `_get_face_app()` pattern.
   - `_get_pyiqa_model()`: `pyiqa.create_metric('topiq_nr', device=device)` with cuda/cpu detection.
   - `_get_aesthetic_model()`: `convert_v2_5_from_siglip(low_cpu_mem_usage=True, trust_remote_code=True)`, move to bfloat16 cuda, return (model, preprocessor). Add float16 fallback for non-bfloat16 GPUs.
   - `normalize_score(value: float, low: float, high: float) -> float`: Linear normalization to [0,1] with clamp.
   - `compute_pose_vector(landmarks) -> list[float]`: Extract ~20 joint angles from 33 MediaPipe landmarks. Define ANGLE_TRIPLETS for both elbows, shoulders, knees, hips, plus spine/neck angles. Normalize angles to 0-1 by dividing by 180. Return zero list if landmarks None.
   - `score_image(image_path: Path, mode: CurationMode, reference_embedding: np.ndarray | None = None) -> ImageScore`:
     a. Load image with cv2
     b. InsightFace: best face det_score, bbox -> area ratio, pose angles, normed_embedding, face-region Laplacian sharpness. Handle no-face case (zeros).
     c. pyiqa TOPIQ-NR: score from model (path accepts str). Normalize with observed range.
     d. Aesthetic V2.5: preprocess + inference, normalize from [1,10] with low=3, high=8.
     e. OpenCV Laplacian: whole-image sharpness. Normalize with low=50, high=1000.
     f. CLIP zero-shot occlusion: encode image + occlusion prompts, compare similarities. Score = clear_sim - occluded_sim normalized.
     g. MediaPipe Pose: compute_pose_vector from landmarks.
     h. Identity similarity: cosine similarity with reference_embedding if provided, else 0.0.
     i. Compute composite score using mode weights from presets.get_weights(). Map signal groups to weight categories:
        - "face" weight applies to: mean(face_confidence, identity_similarity, 1-occlusion_flag)
        - "technical" weight applies to: mean(sharpness_whole, sharpness_face, quality_score)
        - "aesthetic" weight applies to: aesthetic_score
        - "other" weight applies to: face_area_ratio (penalize too small/large)
     j. Return ImageScore with all fields.
   - `score_images(image_paths: list[Path], mode: CurationMode, reference_embedding: np.ndarray | None = None, progress_callback: Callable | None = None) -> list[ImageScore]`:
     Batch wrapper. Score sequentially (GPU models are already batched internally). Call progress_callback(current, total) after each image.

2. Create `klippbok/curation/diversity.py`:
   - `select_diverse_subset(scores: list[ImageScore], target_count: int, clip_embeddings: np.ndarray, pose_vectors: np.ndarray, face_embeddings: np.ndarray, pinned_ids: list[str] | None = None, excluded_ids: list[str] | None = None) -> list[str]`:
     a. Filter out excluded_ids from the pool.
     b. Build index mapping from filtered pool to original scores.
     c. Concatenate normalized embeddings: CLIP (512-D) + Pose (20-D, zero-padded) + Face (512-D). L2-normalize each block before concatenation.
     d. Compute cosine_similarity matrix, np.clip to non-negative.
     e. Adjust target: `adjusted_target = target_count - len(pinned_ids)` (pinned are guaranteed).
     f. Run FacilityLocationSelection(n_samples=adjusted_target, metric='precomputed', optimizer='lazy').fit(sim_matrix).
     g. Get selected_indices from selector.ranking.
     h. Map indices back to image_ids. Prepend pinned_ids.
     i. Return list of selected image_ids.
